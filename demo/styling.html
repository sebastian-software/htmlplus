How the base styles work

The neutral base is built into each element. No extra stylesheet or wrapper class is needed. To connect an application theme, optionally load base.css and add class="h6-base" to a wrapper or control. The neutral palette uses semantic tokens in the spirit of shadcn/ui. Change those tokens or copy a recipe to override a specific part. The components keep their native form behavior.

<link rel="stylesheet" href="./html6-base.css">
<form class="h6-base">
  <!-- Labeled html6 controls go here. -->
</form>

These examples use plain CSS. They do not require React, Tailwind, or shadcn/ui.
